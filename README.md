# Sparsh Roy — Portfolio

Personal portfolio for research and engineering work across AI systems, clinical data, computational biology, human-computer interaction, robotics and social-impact products.

Live at **https://sparshroy.com/**.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vite writes the production site to `dist/client/`. Vercel is configured in `vercel.json` and deploys the `main` branch.

## Content

Public-facing content lives in `src/content.js`. The complete maintained publication list remains at https://sites.mit.edu/sparsh/publications/.
